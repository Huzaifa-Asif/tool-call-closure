# Security Policy

## Supported versions

Until the first public release, only the latest commit is supported. After release, the latest major version will receive security fixes.

## Reporting

Please use GitHub's private vulnerability reporting for this repository. Do not open a public issue for an undisclosed vulnerability. Include the affected version, impact, reproduction, and suggested mitigation when possible.

Never include credentials, private tool output, or production transcripts in a report. You can expect an acknowledgement within seven days. No bug bounty is offered.
