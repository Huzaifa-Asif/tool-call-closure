# Contributing

Thanks for helping improve `tool-call-closure`.

1. Open an issue for behavioral or API changes before substantial work.
2. Keep the package runtime-independent and dependency-free unless a dependency has a compelling, documented benefit.
3. Add tests for normal behavior, malformed input, limits, and races.
4. Run `npm run check` before opening a pull request.
5. Update the README and changelog when behavior changes.

By participating, you agree to follow the Code of Conduct. Contributions are accepted under the MIT license.
